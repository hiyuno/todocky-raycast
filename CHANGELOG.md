# Todocky Changelog

## [Initial Version] - 2026-09-08

- Add Task: form with project picker that stays open for consecutive captures.
- Quick Add Task: capture straight from the Raycast bar into a default project.
- Search Projects: browse projects and their tasks, and add a task to any of them.
- A Todocky that cannot be reached now says so in place, instead of showing an
  empty project list.
